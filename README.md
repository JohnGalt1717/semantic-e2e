# semantic-e2e

Agent skill pack for semantic end-to-end tests. The script stores the contract (intent, preconditions, assertions). A head supplies the means at runtime. Heads are swappable. This repo is not tied to any one app.

Install, once the skills exist:

```bash
npx skills add JohnGalt1717/semantic-e2e
```

`install` is an alias of `add`. Pick `semantic-e2e`, `setup-semantic-e2e`, and the head skills you need.

This repository currently contains the build plan, not the skills. Implement `.agents/plan.md` before publishing skills to the skills.sh index.

## Status

Plan only. Do not treat the install command as working until Phase 0 in the plan is checked off.
